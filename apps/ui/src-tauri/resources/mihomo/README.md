# Source-built native adapter resources

No downloaded/prebuilt runtime is accepted. Run native/stage-mihomo.ps1 with the
reviewed tools/native/mihomo-core source root only after the native owner has built
and tested its pinned module. The desktop build embeds the verified output SHA256.
Windows x64 managed system proxy is the initial backend mode; TUN/DNS/KS and other
platforms remain gated. Staging binaries/notices is not license or release clearance.
