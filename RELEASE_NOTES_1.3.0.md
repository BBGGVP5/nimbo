# Nimbo 1.3.0

Большое обновление на всех платформах: новый дизайн, переработанное VPN-ядро, полные профили Mihomo, новые протоколы, блокировка рекламы и подробная статистика. Ниже — всё, что изменилось с версии 1.2.0.

## Новый дизайн

- Переработаны все экраны: главная, профили, настройки, уведомления, статистика, маршрутизация, приложения, синхронизация, логи и меню трея. Карточки и кнопки выглядят единообразно.
- Кнопка подключения отделена от информации о соединении; остались круглый и компактный варианты, переход между состояниями стал плавнее.
- На компьютере главная и настройки выровнены: карточки одной высоты, без двойных рамок; сортировка и фильтры серверов — в одной строке, поиск настроек и режим «Простой/Расширенный» — рядом.
- Новый значок — облако на графитовом фоне, чёткие иконки для всех масштабов.
- Лучше работают узкие окна, iPad, крупный системный шрифт, светлая и тёмная темы. Если в системе отключены анимации, Nimbo это учитывает.
- Полное описание подписки показывается с переносами строк, без технического мусора.

## Новые возможности

- **Протокол TrustTunnel (`tt://`)** — на Windows, Linux, Android, iPhone и iPad.
- **NaiveProxy на iPhone и iPad** — работает прямо внутри туннеля.
- **Блокировка рекламы.** Переключатель в «Настройки → Маршрутизация» отсекает известные рекламные домены. По умолчанию выключен. Рекламу, встроенную в видео, и приложения со своим зашифрованным DNS он не убирает.
- **Статистика трафика.** Отправлено и получено, текущая скорость, графики и история сессий; сколько трафика идёт через VPN, а сколько напрямую, и число активных соединений. Если ядро не отдаёт показатель, вместо выдуманной цифры стоит прочерк.
- **Состояние сервисов (Android).** Проверка Google, YouTube, ChatGPT и других сервисов через текущее подключение: сразу видно, что открывается, а что недоступно в регионе.
- **Напоминания о подписке (Windows, Linux).** Предупреждение за 3 дня и за сутки до окончания, при окончании, а также при расходе 90% и 100% трафика. Каждое приходит один раз и снова включается после продления.
- **Автоподключение по сети.** На компьютере — отдельно для Wi-Fi, Ethernet и мобильной сети, на iPhone — через On Demand. Можно исключить доверенные Wi-Fi сети по имени. Ручное отключение ставит автоматизацию на паузу.
- **Dynamic Island на iPhone** — статус VPN, можно скрыть отдельным переключателем.
- **Быстрая смена сервера из трея.** Если избранных нет, трей показывает текущий сервер и самые быстрые.

## Профили Mihomo

- Полные YAML-профили с исходными группами и правилами: вкладки категорий, карточки узлов, выбор группы и сервера.
- Проверка задержки сразу для всех узлов и отдельно для каждого. На компьютере и Android — без включения VPN.
- На iPhone профили восстанавливаются из резервной копии без повторного скачивания.
- Исправлен пустой дубль «· Mihomo» при синхронизации Android и компьютера.

## Подключение и стабильность

- Переработано управление VPN-сессиями: запуск, остановка, смена сервера и восстановление после сбоя работают надёжнее, устаревшие проверки больше не мешают новому подключению.
- **Windows:** TUN-режим и режим TUN + Proxy для Mihomo через системный помощник, постоянный Kill Switch. TUN на Windows 10 запускается с первого раза, DNS в TUN-режиме работает надёжнее, трафик больше не блокируется при повторном запуске с Kill Switch.
- **Linux:** TUN-режим Mihomo через системный помощник.
- **Android:** исправлен DNS в момент подключения в некоторых сетях; мягкий лимит памяти ядра — автоматический или свой; понятные подсказки, если уведомление-пилюля недоступно.
- **iPhone и iPad:** приложение больше не зависает при запуске; после переустановки остаётся «тем же устройством» для подписки (раньше при лимите устройств приходила ошибка 404); клавиатура больше не оставляет чёрную полосу; интерфейс не подтормаживает при обновлении подписок и замере задержки.

- Кнопки раскрытия подписок, пинга и обновления выровнены; нажатие на них больше не выбирает сервер случайно.

## Установка

| Платформа | Файл |
|---|---|
| Android (большинство телефонов) | `Nimbo_v1.3.0_arm64_v8a.apk` |
| Android (старые 32-битные) | `Nimbo_v1.3.0_armeabi_v7a.apk` |
| Android (если не уверены) | `Nimbo_v1.3.0_universal.apk` |
| Windows | `NimboSetup_1.3.0_x64.exe` (также x86 и ARM64) |
| Linux | `.AppImage`, `.deb` или `.rpm` для x64 и ARM64 |
| iPhone и iPad | `Nimbo_v1.3.0_ios_resignable.ipa` — для переподписи своим сертификатом |
