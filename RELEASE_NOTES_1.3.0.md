# Nimbo 1.3.0

Первый стабильный выпуск ветки 1.3: новый дизайн, переработанное VPN-ядро и полные профили Mihomo из бет — теперь для всех. Ниже — что появилось и исправлено после 1.3.0 Beta 1.

## Новое

- **Протокол TrustTunnel (`tt://`)** — на Windows, Linux, Android, iPhone и iPad. Ссылки и подписки с такими серверами импортируются как обычные.
- **Состояние сервисов (Android).** Проверка Google, YouTube, ChatGPT и других сервисов через текущее подключение: сразу видно, что открывается, а что недоступно в регионе.
- **Напоминания о подписке (Windows, Linux).** Nimbo заранее предупредит, что подписка заканчивается через 3 дня, через сутки и когда она истекла, а также когда израсходовано 90% и 100% трафика. Каждое напоминание приходит один раз; после продления они снова включаются.
- **Быстрая смена сервера из трея.** Если избранных серверов нет, меню в трее показывает текущий сервер и самые быстрые — переключиться можно, не открывая окно.
- **NaiveProxy на iPhone и iPad** — работает прямо внутри туннеля.
- **Статус VPN в Dynamic Island** на iPhone.

## Улучшения

- **Обновлённый вид на компьютере.** Главная и настройки выровнены: карточки одной высоты, у поиска и списков нет двойных рамок, сортировка и фильтры серверов — в одной строке, поиск настроек и режим «Простой/Расширенный» — рядом.
- **Приложение стало легче.** Универсальный APK для Android — 75 МБ вместо 132, пакеты для Linux — на 13 МБ меньше, установщик Windows тоже уменьшился.
- **Обновлены ядра:** Xray 26.10.31, Mihomo 1.19.33.

## Исправления

**iPhone и iPad**
- Приложение больше не зависает на первом экране при запуске.
- После переустановки приложение остаётся «тем же устройством» для подписки: раньше при лимите устройств панель отвечала ошибкой 404.
- Клавиатура больше не оставляет чёрную полосу под полями ввода.
- Интерфейс не подтормаживает при обновлении подписок, проверке профилей Mihomo и замере задержки.

**Windows**
- TUN-режим на Windows 10 запускается с первого раза: Nimbo дожидается создания сетевого адаптера, а не прерывает запуск.
- Надёжнее работает DNS в TUN-режиме.
- Исправлена загрузка Xray и правил маршрутизации, которая перестала работать, когда разработчики Xray удалили старые версии.

**Android**
- Исправлена работа DNS в момент подключения в некоторых сетях.

## Установка

| Платформа | Файл |
|---|---|
| Android (большинство телефонов) | `Nimbo_v1.3.0_arm64_v8a.apk` |
| Android (старые 32-битные) | `Nimbo_v1.3.0_armeabi_v7a.apk` |
| Android (если не уверены) | `Nimbo_v1.3.0_universal.apk` |
| Windows | `NimboSetup_1.3.0_x64.exe` (также x86 и ARM64) |
| Linux | `.AppImage`, `.deb` или `.rpm` для x64 и ARM64 |
| iPhone и iPad | `Nimbo_v1.3.0_ios_resignable.ipa` — для переподписи своим сертификатом |

Обновление ставится поверх 1.2.0 и бет 1.3.0, настройки и подписки сохраняются.
