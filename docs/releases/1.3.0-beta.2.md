# Nimbo 1.3.0 Beta 2

Черновик описания выпуска. Пакеты и приёмочные проверки ещё не означают публикацию релиза или проверку каждого физического устройства.

## Настройки без перегруза

- Простой режим показывает основные разделы; расширенный открывает технические параметры. Переключение режима не сбрасывает настройки соединения.
- Поиск находит и дополнительные параметры, даже если расширенный режим выключен.
- Из обычных настроек можно подготовить отчёт об ошибке, посмотреть его содержимое и отправить вручную. Автоматической отправки нет; ссылки подписок, ключи и произвольный текст журналов в новый отчёт не включаются.

## Более осторожный автовыбор

- Переработана оценка кандидатов: свежая проверка через настроенный маршрут отличается от обычной доступности адреса, старого пинга и неуспешной попытки.
- На desktop учитываются смена сессии и конфигурации; устаревший ответ не должен менять новое подключение.
- Для автоматического Xray-маршрута iOS добавлена логика удержания исправного сервера и переключения после подтверждённых сбоев, с задержкой повторного выбора неудачного маршрута.
- На Android неудачная или устаревшая проверка не получает преимущество перед ещё не проверенными кандидатами. Сохранён приоритет обходных серверов в ограниченной сети.

## Запуск и подписки

- На iOS устранено пересечение блокировки хранилища подписки с синхронными уведомлениями интерфейса. Подсказки выбранного сервера читаются прежде всего из Keychain; ошибка чтения не подменяется старым значением настроек.
- Обновление системного индекса быстрых команд вынесено из синхронного запуска приложения. Сборка проверяет наличие настоящих метаданных App Intents для приложения и элемента Пункта управления.
- На Windows переработана обработка повторного запуска и активации уже открытого окна. Это не подтверждение устранения всех причин вылета на каждом компьютере.

## Ядра и состав сборок

- Xray / LibXray обновлены до **26.10.10**. Сохранены объединённые адаптеры Nimbo для поддерживаемых ядер и протоколов; обновлены проверки фактических нативных файлов и лицензий.
- Текущие закреплённые версии: **Mihomo 1.19.32**, **AmneziaWG 3.1.20260828**, **NaiveProxy 154.0.8037.49-4** на Android/desktop. iOS использует отдельный совместимый канал **Cronet/Naive 150.0.7871.63**, а не Chromium 154.
- В Android-пакетах сохранены обязательные файлы лицензий, которые стандартный фильтр скрытых каталогов исключал из ресурсов.

## Перед публикацией

- Нужна проверка запуска новой IPA, подключения/отключения и обновления подписки на iPhone. Присланный отчёт о взаимной блокировке относится к прежней сборке 180; он не доказывает причину чёрного экрана экспериментальной xtool-сборки 181.
- Экспериментальная xtool IPA без App Intents metadata не является проверенным кандидатом на выпуск. Для повторной проверки собрана обычная Xcode IPA: build181, исходники7695a0b3ef25; метаданные, расширения и ресурсы проверены.
- В Windows Mihomo Both/Kill Switch наблюдался плавающий DNS-таймаут. Два последующих полных Windows-прогона прошли, но причина первого сбоя пока не установлена; это не считается подтверждённым исправлением.
- Локальные Android APK пока не подписаны релизным ключом. Неподписанные файлы нельзя выдавать за готовое обновление опубликованного приложения.
