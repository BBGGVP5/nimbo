# Nimbo Android: быстрый старт

Nimbo — Android VPN-клиент на базе `libXray`. Текущая реализация использует Android
`VpnService`, TUN inbound и Xray outbounds; старые инструкции для `sing-box`/`libbox`
к этому исходному коду не относятся.

## Сборка

В проекте должен находиться `app/libs/libxray.aar`. Из корня проекта выполните:

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat lintDebug assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/`.

## Схема соединения

1. `MyVpnService` создаёт Android TUN-интерфейс.
2. `XrayManager` генерирует или нормализует клиентский Xray JSON.
3. TUN-трафик направляется в выбранный outbound или balancer.
4. Перед состоянием «Подключено» Nimbo выполняет HTTPS-проверку через отдельный
   loopback HTTP inbound `127.0.0.1:2080`.

Служебный HTTP inbound привязан только к loopback и маршрутизируется отдельным
first-match правилом. Он предназначен для внутренних проверок Nimbo, а не для
публикации прокси в локальную сеть.

## Показатели задержки

- **TCP до ноды** — прямой `Socket.connect(host, port)`. Это быстрый предварительный
  тест доступности ноды, а не задержка интернета внутри VPN.
- **Через VPN** — HTTP-запрос к контрольному URL через активный Xray outbound.

Для воспроизводимого сравнения клиентов и проверки восстановления используйте
[методику сетевой валидации](docs/network-validation.md).

## Поддерживаемые конфигурации

Клиент импортирует VLESS, VMess, Trojan, Shadowsocks, Hysteria и полные Xray JSON-
шаблоны. Фактическая поддержка конкретного transport зависит от приложенного
`libxray.aar` и валидности серверной конфигурации.
