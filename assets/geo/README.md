# Общие данные карты Нимбо

`nimbo-world-map.json` — один источник для карты на главном экране на Android, iOS и десктопе.
Каждая платформа копирует/подключает этот файл в свои ресурсы, а не генерирует своё.

## Формат

- `grid` — равнопромежуточная сетка (lon/lat) с шагом `step` градусов: `cols` × `rows`,
  верхний левый угол `lonWest`/`latNorth`. Широты от 80° с.ш. до 56° ю.ш. (без Антарктиды).
- `land[r]` — строка `r` сверху вниз, hex, старший бит первым. Бит `c` = 1 → в центре клетки
  `(lon = lonWest + (c + 0.5) * step, lat = latNorth - (r + 0.5) * step)` суша. Каждая единица — одна точка карты.
- `countries` — ISO 3166-1 alpha-2 → `[lat, lon]` типичного города дата-центра страны
  (Франкфурт для DE, Амстердам для NL и т.д.). Сюда ставится флаг сервера и конец дуги маршрута.
- `timezones` — IANA-зона устройства → `[lat, lon]`. Начало дуги («вы здесь»).
  Порядок: зона устройства → страна региона/локали устройства из `countries` → Москва. Сеть не используется.

## Проекция

Для отображения — простая равнопромежуточная (x = lon, y = lat) с поправкой по ширине `cos(центральной широты)`,
окно подгоняется под bbox «вы здесь» + видимые серверы с отступом.

## Источник

Суша — Natural Earth 1:110m land (public domain) из пакета `world-atlas@2.0.2`.
Генератор — `tools/geo/gen_map.py` (запуск: `py -I tools/geo/gen_map.py land-110m.json assets/geo/nimbo-world-map.json`).
MT (Мальта) в масштабе 1:110m не попадает на сушу — флаг рисуется без подложки, это ожидаемо.
