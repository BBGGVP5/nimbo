# 🤖 Что нового на Android

## 🌐 Всё о сети — в «Соединениях»

Раздел стал единым центром управления сетью. Здесь по-прежнему видны активные подключения и правила маршрутизации, а ниже появились новые возможности:

- автоматические профили для домашней сети, публичного Wi‑Fi и роуминга;
- помощник для Wi‑Fi, где перед началом VPN нужно пройти авторизацию;
- умная группа серверов, которая выбирает стабильный узел и не переключается из-за случайной разницы в несколько миллисекунд;
- месячный лимит трафика с предупреждениями;
- понятный ответ на вопрос «Почему отключилось?» по последним событиям соединения.

## 📳 Больше вариантов виброотклика

- Теперь доступно шесть характеров отклика: мягкий, чёткий, двойной, волна, пульс и пружина.
- Чтобы снова почувствовать выбранный вариант, достаточно нажать на него повторно.
- После успешного подключения Nimbo подтверждает готовность отдельным откликом.
- Общую силу вибрации и сам виброотклик по-прежнему можно настроить или отключить.

## 🎨 Аккуратнее и понятнее

- Вложенные страницы получили единый заголовок без лишней большой плашки.
- Экран обновления стал чище, а размер APK отображается на выбранном языке.
- Исправлены светлые квадраты и швы на фоне стеклянных элементов.
- Пометка Beta на адаптивной иконке стала меньше и закреплена в правом верхнем углу, не закрывая облако.
- Нижняя панель умеет плавно скрываться при прокрутке; поведение включается отдельно в настройках оформления.

## 🛡 Обход блокировок по TLS

Nimbo получает подходящие параметры обхода вместе с подпиской. Сервис может менять их без выпуска новой версии приложения — пользователю достаточно обычного обновления подписки.

# 🖥️ Что нового на Windows и Linux

## ⚡ Быстрые правила из активных соединений

Рядом с текущим соединением теперь можно сразу выбрать действие: отправить программу через VPN, оставить её напрямую или заблокировать адрес. Новое правило применяется без долгого поиска нужного пункта в настройках.

## 🚀 «Запустить через Nimbo»

- Выберите EXE-файл внутри приложения — Nimbo сначала подготовит правило и туннель, а затем откроет программу.
- В Windows можно добавить одноимённый пункт в контекстное меню EXE-файлов Проводника.
- Программа не запускается до готовности маршрута, поэтому её первые подключения не успевают уйти мимо VPN.

## 🪟 Больше управления прямо из Windows

- Из компактного меню Nimbo теперь можно быстро открыть «Соединения» и «Приложения».
- Действия с правилами и приложениями стали ближе, а состояния — понятнее.
- Для Windows x64, x86 и ARM64 собраны фирменные установщики Nimbo; для Linux x64 доступен такой же отдельный установщик.

## 🛡 Обход блокировок из подписки

Параметры TLS-обхода приходят вместе с подпиской и применяются только к нужным серверам. Сервис может обновлять их без новой версии Nimbo.
<!-- nimbo:desktop:end -->

# Небольшие исправления

- Настройки сети и обновлений аккуратнее переживают смену подключения.
- Ошибочные или неполные данные подписки не мешают обычному запуску VPN.
- Обновлены тексты и подписи, чтобы новые функции было проще найти без инструкции.

> [!NOTE]
> Профили сети, лимиты и умные группы работают локально на устройстве. Nimbo не отправляет историю ваших сетей на внешний сервер.
